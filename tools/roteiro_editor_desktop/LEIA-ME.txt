EDITOR DE ROTEIROS ROLEPLAY2026 - WINDOWS
VERSAO DE AUTORIA: IMAGEM PRIMEIRO

Este programa e independente do Roleplay2026.
Nao precisa instalar Python, Streamlit, venv ou Miniconda.

FLUXO: IMAGEM PRIMEIRO
1. Abra Editor_Roteiros_ROLEPLAY2026.exe.
2. No painel direito, clique em ABRIR IMAGEM ou ABRIR LOTE.
3. Observe a imagem enquanto escreve o roteiro.
4. Clique em + DESCRICAO DESTA IMAGEM para criar uma [DESCRICAO] ja ligada a imagem atual.
5. Escreva a descricao, FALAS e PENSAMENTOS olhando para a referencia visual.
6. Use Anterior / Proxima para navegar pelo lote de imagens.
7. Clique em Validar / atualizar quando quiser conferir as linhas geradas.
8. Clique em EXPORTAR ROTEIRO + IMAGENS ao finalizar.

SAIDA
A pasta exportada contem:
- roteiro.xlsx
- roteiro.csv
- roteiro.tsv
- projeto_roteiro.json
- imagens/*.webp

CABECALHO OFICIAL
package_id | script_version | line_id | order | instruction | status | image_id

As imagens sao convertidas para WebP e recebem numeracao automatica, por exemplo:
camilly1.webp
camilly2.webp
camilly3.webp

A imagem aberta no painel direito e referencia de autoria. Ela so recebe image_id quando for associada a uma [DESCRICAO].

O arquivo projeto_roteiro.json permite continuar a edicao posteriormente enquanto as imagens originais permanecerem acessiveis no PC.

O programa nao envia nem altera arquivos no GitHub ou Google Sheets. A transferencia final continua manual e controlada por voce.
